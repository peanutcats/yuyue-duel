# 十六根羽毛：场景、CG 与音乐

本目录现用于第三版剧本《十六根羽毛》。旧场景、全部旧配音、语音清单与微信语音分包已移除。

`sixteen/` 含 31 幅原创场景和 12 幅关键 CG，采用与主游戏一致的深蓝环境、金蓝灯光、明亮服装色和描边人物。CG 直接复用 `js/char.js` 的角色骨骼与外形，不再另画一套角色。图形母版在 `js/story-art.js`：网页插画卡片读取导出的 SVG；动态演出与微信均通过同一母版直接绘制 Canvas。`tools/story-svg-context.js` 将实际人物与场景路径导出为 SVG，保持两端一致。故事画面使用缓存、缓慢推镜、浮尘、雨、蒸汽与羽毛转场。`sixteen/index.html` 是全套美术册。

重新导出插画：

```sh
node tools/export-story-art.js
```

配乐和动作音由 `tools/sound-design.js` 原创合成：16 音钢琴主题按剧情逐渐补齐，直到终章丁丁说出“我喜欢你。”时首次完整奏出。穿线夹头、断线、读球、意图、包子、预测、江水和鹅声均为新音效。音乐位于微信 `summer-score` 分包；网页版本位于 `sixteen/audio/`。重建两端音频：

```sh
npm run build:wechat
```

没有新人物配音，也不调用语音合成服务。对白使用字幕；关键静音段停止配乐，只保留动作及环境声。
