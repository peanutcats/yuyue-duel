# 羽跃对决

侧视 1v1 网页羽毛球对战游戏。纯 HTML5 Canvas + 原生 JS，无需构建、无外部素材，打开即玩，适配电脑与手机。

`main` 是用于 Vercel 的 V10 版本，在线对战保留 PeerJS + Cloudflare TURN。服务器统一计算的 WebSocket 版本单独保存在 `codex/server-authority` 分支；两种版本的房间不互通。

## 运行

- **直接打开**：双击 `index.html` 即可游玩（快速对战 / 同屏对战 / 自由练习）。
- **本地服务器**（推荐，在线对战的邀请链接需要 http 地址）：
  ```bash
  python3 tools/serve.py
  ```
  然后访问 http://localhost:8765 （开发服务器禁用了缓存；任何静态服务器都可以）。
- **局域网联机**：用电脑运行上面的服务器，手机访问 `http://电脑IP:8765` 即可与电脑上的玩家在线对战。
- **更新版本**：修改 JS/CSS 后把 `index.html` 里的 `?v=11` 加一，避免玩家浏览器缓存旧代码。
- **部署**：整个目录是静态文件，可直接放到 GitHub Pages、Netlify、Vercel、任意 Nginx 等。

## 玩法要点

| 操作 | 键盘 | 触屏 |
| --- | --- | --- |
| 前后移动 | A / D 或 ← / → | 左下 ← / → 箭头，按住移动 |
| 起跳 | W / ↑ / 空格 | 跳 |
| 高远球（低位时为挑球） | J 或 Z | 高远 |
| 吊球（近网时为网前轻放） | K 或 X | 吊球 |
| 扣杀（需起跳、足够高度与体力） | L 或 C | 扣杀 |
| 角色技能（能量环充满后） | I 或 V | 扣杀键上方的技能键 |
| 暂停 | Esc / P | 左上角按钮 |

同屏双人：左方 `A D W + F G H`，右方 `← → ↑ + , . /`（或小键盘 1 2 3）。

- **击球判定**：按键后有约 0.17 秒的有效挥拍窗口，最佳时刻约在按键后 0.11 秒。羽毛球必须实际过网、球头完全进入己方半场，并进入以肩为中心的“甜区圆环”才能击中；撞网球不能隔网接回。太早挥空、太晚过身；位置与时机越准，回球越快越稳。跑动中、低点救球、接杀时回球质量会下降。
- **方向修饰**：击球瞬间按住“向网”方向，高远变平高、吊球变劈吊、扣杀打近；按住“向后”，扣杀打深。
- **体力**：起跳 12、扣杀 24，移动与普通回球不消耗；停止高消耗动作 1 秒后开始恢复，每分结束回满。体力不足时只能低跳，扣杀会变成平抽。
- **规则**：7 分制，需领先 2 分，10:10 后先得 11 分者胜。压线算界内，得分方发球。发球时看头顶力度条，指针越靠中间发球越稳。

## 美术与表现

- **三座场馆**（菜单中可选或随机，在线对战跟随房主）：
  - 星光体育馆：夜场聚光灯光柱与浮尘、六排可欢呼的观众、闪光灯、滚动 LED 广告板、裁判椅、抛光木地板倒影。
  - 落日天台：黄昏天空与太阳光晕、两层城市天际线与灯窗、飘动的云和飞鸟、随风摆动的串灯、暖光萤火、长投影与镜头光晕。
  - 霓虹电竞场：闪烁霓虹招牌、扫动激光、荧光棒、发光网格地面，球场线会随击球与扣杀脉冲发光。
- **角色**：骨骼姿态（IK 腿 + 两段手臂），分层着色与描边、面部表情、视线跟随羽毛球、马尾 / 头带弹簧摆动；有准备、跑动、起跳、扣杀反弓、低位弓步、得分庆祝与失分沮丧等姿态。击球与发球时拍面精确落在物理接触点上。
- **镜头**：发球时推近发球方，扣杀和救球时冲击推镜并震屏，背景层带视差。
- **特效**：丝带状球迹（扣杀为火焰色）、挥拍光弧、跳杀残影、火花 / 光晕 / 冲击环 / 速度线、落羽、落点光柱与地面波纹、球网波动、得分彩带、胜利彩带雨与场馆联动（观众欢呼、LED 快讯）。
- **界面**：转播风记分牌（头像、体力条、比分弹跳、发球标记、赛点徽章、回合计数）、斜切得分横幅、玻璃质感菜单、场馆缩略图选择、结算页头像与数据对比条。
- **自动画质**：持续掉帧时自动关闭倒影、残影等高开销效果并降低分辨率，流畅后再恢复。

## 模式

- **故事模式**：6 章 18 关的主线剧情《守护星光体育馆》。转学生凌风在储物间捡到会说话的羽毛球“毛毛”，为了让老球馆免于拆除，和羽跃社的伙伴一起冲击星光杯。关卡由对话和多种玩法组成：
  - 发球机练习（接球、高远、吊球、接杀、跳杀）、**米字步步法**小游戏（踩点 / 起跳 / 挥拍光圈）、**网前发球**挑战、知识**问答**、**选择题**（选错球速号，下一场球会“飘”）。
  - 特殊比赛：每 2 分换向的**穿堂风**、只在球和选手周围有光的**停电夜**、空气稀薄的**高原球馆**、连赢三场的**车轮战**、对阵假动作大师的**星光杯决赛**。
  - 每关最多 3 星（附加目标见结算页），通关解锁角色、装备与知识卡；进度保存在浏览器本地（`localStorage`）。
- **角色与装备**：7 名可选角色（凌风、沧澜默认可用；小红、冉冉、瑞宝、丁丁、田楚在故事中加入），各有基础属性与独特技能：

  | 角色 | 技能 | 效果 |
  | --- | --- | --- |
  | 凌风 | 破空一击 | 下一拍必定完美、判定范围扩大，扣杀更快 |
  | 沧澜 | 潮汐回气 | 体力回满，6 秒内起跳扣杀不耗体力 |
  | 小红 | 烈焰重杀 | 下一记扣杀 +22% 球速、对手接球质量大减 |
  | 冉冉 | 缓时·冉冉 | 飞向自己的球放慢到 45%，持续 2.8 秒 |
  | 瑞宝 | 移动城墙 | 7 秒内够球范围 +50%，接杀不降质量 |
  | 丁丁 | 疾风闪步 | 3.5 秒内移动 ×1.6、启动 ×2.2 |
  | 田楚 | 镜花水月 | 下一拍为假动作：幻影分叉、对手判断变慢、落点提示消失 |

  装备：6 支球拍（重量 U 数、平衡点、中杆软硬）、4 种球线（线径与弹性）、20–30 磅可调磅数（故事 2-2 解锁）、5 双球鞋（含一双会打滑的“旧跑鞋”）。装备改变力量、控制、网前、甜区、防守、移动、弹跳、体力、挥拍耗时、落地硬直等数值，页面实时显示综合能力与加成。
- **羽球图鉴**：22 张知识卡（器材 / 技术 / 规则 / 战术 / 趣闻），在故事中收集。
- **快速对战**：使用你选择的角色与装备，对手从全部角色中随机抽取（标准装备），可在页面上关闭角色技能。简单 / 普通 / 困难 AI，难度只影响反应时间、落点判断误差、挥拍时机误差、回位速度和球路选择；普通及以上会读取你连续使用的同类球路并提前站位（屏幕提示“预判！”）。
- **好友对战**
  - 在线：基于 WebRTC（PeerJS），房主权威模拟，好友上传输入、接收最高 60Hz 的最新快照并插值渲染，对好友的挥拍做了延迟补偿。房主创建房间后把 4 位房间码或邀请链接（`?room=XXXX`）发给好友，好友打开链接会自动加入。
  - 同屏：一台设备两人对战（键盘左右分区；手机横屏两侧各一套按键）。
- 在线与同屏对战不启用角色、装备与技能，双方能力完全相同。
- **自由练习**：接球 / 高远球 / 吊球 / 跳杀（使用所选角色与装备的属性）。发球机喂球，显示预计落点（黄圈）、理想站位（青色虚线）、挥拍倒计时圆环与“起跳！/挥拍！”提示，以及落点目标区和失败原因。

## 在线对战说明

联机分两步：先通过 PeerJS 公共信令服务器"找到房间"，再在两台设备之间建立数据通道。数据通道优先**直连**（STUN 探测公网地址）；当一方处在对称型 NAT 后（国内手机 4G/5G、校园网、公司网很常见）时直连会失败，这时必须经 **TURN 中转**。

### 配置 Cloudflare TURN（推荐，部署到 Vercel 后必做）

游戏通过本站的 `/api/turn`（`api/turn.js`，Vercel 函数）向 Cloudflare 申请**临时** TURN 凭证。密钥只保存在 Vercel 服务器端，浏览器拿到的是 4 小时后失效的临时用户名/密码。

1. 登录 [Cloudflare 控制台](https://dash.cloudflare.com)，进入 **Realtime（实时）→ TURN Server**（界面名称可能略有不同），点击创建，得到 **Turn Token ID** 与 **API Token**。Cloudflare TURN 有免费额度，超出部分按流量计费，详见其定价页。
2. 打开 Vercel 项目 → **Settings → Environment Variables**，添加：
   - `CF_TURN_KEY_ID` = Turn Token ID
   - `CF_TURN_API_TOKEN` = API Token
3. 在 **Deployments** 里对最新部署点 **Redeploy**（环境变量只对新部署生效）。
4. 验证：浏览器打开 `https://你的域名/api/turn`，应返回包含 `iceServers` 的 JSON；进入对战后，延迟旁会显示 **直连** 或 **中转**。

未配置时接口返回 503，游戏自动退回仅直连，并在房间页提示"未获取到中转服务器"。本地开发时可这样启用：

```bash
CF_TURN_KEY_ID=xxx CF_TURN_API_TOKEN=yyy python3 tools/serve.py
```

### 其他说明

- 联机组件从 jsDelivr / unpkg 按需加载，需要联网。STUN 使用国内可达的 `stun.miwifi.com`、`stun.chat.bilibili.com` 及 Cloudflare、Google 的服务器。
- 若所在网络无法访问 PeerJS 公共信令服务，可自建：
  ```bash
  npm install -g peer && peerjs --port 9000 --path /peer
  ```
  然后在 `js/net.js` 的 `YY.NET_CONFIG.peer` 中加入 `host / port / path / secure` 配置。
- **微信 / QQ 内打开**：应用内置浏览器对 WebRTC 支持不完整，检测到时会提示好友点右上角「在浏览器打开」。
- **掉线与离开**：任一方切到后台（或锁屏）时会发送"暂时离开"心跳，比赛自动暂停并提示对方等待；超过 1.2 秒收不到对方输入/画面也会暂停并显示倒计时，15 秒仍无数据则判定断线，双方回到菜单。
- **加入失败的提示**：房间码不存在会立即提示；找到了房间但通道建立失败时，会区分"没有可用中转服务器"与"直连和中转都未连通"两种情况。
- 调试：两个标签页的 URL 都加 `?loopback=1`，即可通过 BroadcastChannel 在同一浏览器内联机，验证联机逻辑而不依赖 WebRTC。

物理以 120Hz 固定步长运行。羽毛球使用二次空气阻力（终端速度约 11 m/s），因此高远球先快后慢、几乎垂直下落，扣杀出手极快但迅速减速。

运行发球与显示一致性回归：`node --test tools/serve_regression.test.js`。

## 手机横屏与触控

菜单、竖屏提示和对局左上角都提供横屏全屏入口。先立即适配横屏，再申请浏览器全屏与方向锁；不支持时保留 CSS 横屏并明确提示，不能强制隐藏浏览器系统工具栏。支持退出全屏、旋转坐标映射与安全区域。

左侧是独立的 ← / → 移动箭头，按住以全速移动、松开停止；可不抬手滑向另一箭头换向，滑出按键区域停止。两键同时按住时以后按方向为准，松开后恢复仍按住的方向。右下角金色起跳大键为主键，高远、吊球、扣杀沿左侧至上方环绕，独立圆形触区之间留出间隔。支持多指并行，松手、触摸取消、切后台与旋转时自动释放输入。操作区同时使用 touch-action 与非被动 touchend 事件拦截双击缩放，保留每次触摸对应的击球动作；菜单仍使用正常点击，帮助页可滚动。

## 延迟排查与本次修复

- 输入变化立即上传，不等待下一次画面循环；房主每个显示帧最多发送一次最新状态，最高 60Hz，避免低帧率补物理步时批量发送过期快照。
- 独立网络时钟不随扣杀停顿或暂停冻结。稳定网络画面缓冲为 25ms；根据抖动调整到最多 80ms，禁止跨击球或撞网插值。
- 监测 DataChannel 积压并合并尚未发送的旧位置，保留全部击球/得分事件和累积按键计数。仍使用可靠通道；已经进入浏览器网络栈的丢包重传不能在应用层撤回。
- 底部显示「往返 / 直连或中转 / 画面缓冲」，可区分网络本身与显示缓冲。往返是应用层 ping/pong，并不等于单向延迟。

针对 Mac mini 与 Windows、线上域名 `yuyue.evencode.qzz.io` 约 800ms 的体感延迟，上一轮联机排查时，线上加载 v6，TURN 接口返回 Cloudflare 的 UDP/TCP/TLS 中转地址，说明中转已配置；网络同步优化自 v8 引入。尚未获取双方对局的真实 ICE 线路数据，不能断定 800ms 来自 Vercel 或某个中转节点。

排查顺序：先两端使用最新版且保持前台，对照同一 Wi-Fi 与原网络的「往返」；若直连仍高，检查两端网络拥塞并交换房主（选择帧率稳定的设备）；若中转时高，应对比靠近双方、双方运营商均可达的 TURN 节点。自建 coturn 需服务器、UDP 连通性与临时凭证接口，不能只把静态网站换一个部署区域。网站与 PeerJS 信令负责加载/建连，游戏数据走实际选中的 WebRTC 线路。

可进一步采用独立的无序、限重传状态通道 + 可靠事件通道，以及带确认序号的本地移动预测；这些需要额外处理丢包、校正与击球公平性，本次不以猜测球路替代权威碰撞。

验证：`node --test tools/serve_regression.test.js tools/net_latency.test.js tools/turn_api.test.js`。
技术依据：[方向锁限制](https://developer.mozilla.org/en-US/docs/Web/API/ScreenOrientation/lock)、[DataChannel 发送队列](https://developer.mozilla.org/en-US/docs/Web/API/RTCDataChannel/bufferedAmount)、[PeerJS 通道与缓冲接口](https://peerjs.com/client/api/data-connection)。

移动触控回归（需 Playwright CLI）：先启动本地服务器并打开游戏，再运行 `mkdir -p output/playwright`，将 `tools/touch_controls.browser.js` 的内容传给 CLI 的 `run-code`。覆盖快速连点防缩放、每次点击仅触发一次、左右按住与滑动换向、三指移动加起跳加击球、独立松手、触摸取消、同屏双方隔离、横屏旋转与触区间距；可分别用 Chromium 与 WebKit 执行。
