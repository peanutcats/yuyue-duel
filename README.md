# 羽跃对决

侧视 1v1 网页羽毛球对战游戏。纯 HTML5 Canvas + 原生 JS，无需构建、无外部素材，打开即玩，适配电脑与手机。

## 运行

- **直接打开**：双击 `index.html` 即可游玩（快速对战 / 同屏对战 / 自由练习）。
- **本地服务器**（推荐，在线对战的邀请链接需要 http 地址）：
  ```bash
  python3 tools/serve.py
  ```
  然后访问 http://localhost:8765 （开发服务器禁用了缓存；任何静态服务器都可以）。
- **局域网联机**：用电脑运行上面的服务器，手机访问 `http://电脑IP:8765` 即可与电脑上的玩家在线对战。
- **更新版本**：修改 JS/CSS 后把 `index.html` 里的 `?v=4` 加一，避免玩家浏览器缓存旧代码。
- **部署**：整个目录是静态文件，可直接放到 GitHub Pages、Netlify、Vercel、任意 Nginx 等。

## 玩法要点

| 操作 | 键盘 | 触屏 |
| --- | --- | --- |
| 前后移动 | A / D 或 ← / → | 左下滑动条 |
| 起跳 | W / ↑ / 空格 | 跳 |
| 高远球（低位时为挑球） | J 或 Z | 高远 |
| 吊球（近网时为网前轻放） | K 或 X | 吊球 |
| 扣杀（需起跳、足够高度与体力） | L 或 C | 扣杀 |
| 暂停 | Esc / P | 左上角按钮 |

同屏双人：左方 `A D W + F G H`，右方 `← → ↑ + , . /`（或小键盘 1 2 3）。

- **击球判定**：按键后有约 0.17 秒的有效挥拍窗口，最佳时刻约在按键后 0.11 秒。羽毛球必须实际过网、球头完全进入己方半场，并进入以肩为中心的“甜区圆环”才能击中；撞网球不能隔网接回。太早挥空、太晚过身；位置与时机越准，回球越快越稳。跑动中、低点救球、接杀时回球质量会下降。
- **方向修饰**：击球瞬间按住“向网”方向，高远变平高、吊球变劈吊、扣杀打近；按住“向后”，扣杀打深。
- **体力**：起跳 12、扣杀 24，移动与普通回球不消耗；停止高消耗动作 1 秒后开始恢复，每分结束回满。体力不足时只能低跳，扣杀会变成平抽。
- **规则**：7 分制，需领先 2 分，10:10 后先得 11 分者胜。压线算界内，得分方发球。发球时看头顶力度条，指针越靠中间发球越稳。

## 美术与表现

- **三座场馆**（菜单中可选或随机，在线对战跟随房主）：
  - 星光体育馆：夜场聚光灯光柱与浮尘、六排可欢呼的观众、闪光灯、滚动 LED 广告板、裁判椅、抛光木地板倒影。
  - 落日天台：黄昏天空与太阳光晕、两层城市天际线与灯窗、飘动的云和飞鸟、随风摆动的串灯、暖光萤火、长投影与镜头光晕。
  - 霓虹电竞场：闪烁霓虹招牌、扫动激光、荧光棒、发光网格地面，球场线会随击球与扣杀脉冲发光。
- **角色**：骨骼姿态（IK 腿 + 两段手臂），分层着色与描边、面部表情、视线跟随羽毛球、马尾 / 头带弹簧摆动；有准备、跑动、起跳、扣杀反弓、低位弓步、得分庆祝与失分沮丧等姿态。击球与发球时拍面精确落在物理接触点上。
- **镜头**：发球时推近发球方，扣杀和救球时冲击推镜并震屏，背景层带视差。
- **特效**：丝带状球迹（扣杀为火焰色）、挥拍光弧、跳杀残影、火花 / 光晕 / 冲击环 / 速度线、落羽、落点光柱与地面波纹、球网波动、得分彩带、胜利彩带雨与场馆联动（观众欢呼、LED 快讯）。
- **界面**：转播风记分牌（头像、体力条、比分弹跳、发球标记、赛点徽章、回合计数）、斜切得分横幅、玻璃质感菜单、场馆缩略图选择、结算页头像与数据对比条。
- **自动画质**：持续掉帧时自动关闭倒影、残影等高开销效果并降低分辨率，流畅后再恢复。

## 模式

- **快速对战**：简单 / 普通 / 困难 AI。AI 和玩家的移动、跳跃、体力参数完全相同，难度只影响反应时间、落点判断误差、挥拍时机误差、回位速度和球路选择；普通及以上会读取你连续使用的同类球路并提前站位（屏幕提示“预判！”）。
- **好友对战**
  - 在线：基于 WebRTC（PeerJS），房主权威模拟，好友上传输入、接收 60Hz 快照并插值渲染，对好友的挥拍做了延迟补偿。房主创建房间后把 4 位房间码或邀请链接（`?room=XXXX`）发给好友，好友打开链接会自动加入。
  - 同屏：一台设备两人对战（键盘左右分区；手机横屏两侧各一套按键）。
- **自由练习**：接球 / 高远球 / 吊球 / 跳杀。发球机喂球，显示预计落点（黄圈）、理想站位（青色虚线）、挥拍倒计时圆环与“起跳！/挥拍！”提示，以及落点目标区和失败原因。

## 在线对战说明

联机分两步：先通过 PeerJS 公共信令服务器"找到房间"，再在两台设备之间建立数据通道。数据通道优先**直连**（STUN 探测公网地址）；当一方处在对称型 NAT 后（国内手机 4G/5G、校园网、公司网很常见）时直连会失败，这时必须经 **TURN 中转**。

### 配置 Cloudflare TURN（推荐，部署到 Vercel 后必做）

游戏通过本站的 `/api/turn`（`api/turn.js`，Vercel 函数）向 Cloudflare 申请**临时** TURN 凭证。密钥只保存在 Vercel 服务器端，浏览器拿到的是 4 小时后失效的临时用户名/密码。

1. 登录 [Cloudflare 控制台](https://dash.cloudflare.com)，进入 **Realtime（实时）→ TURN Server**（界面名称可能略有不同），点击创建，得到 **Turn Token ID** 与 **API Token**。Cloudflare TURN 有免费额度，超出部分按流量计费，详见其定价页。
2. 打开 Vercel 项目 → **Settings → Environment Variables**，添加：
   - `CF_TURN_KEY_ID` = Turn Token ID
   - `CF_TURN_API_TOKEN` = API Token
3. 在 **Deployments** 里对最新部署点 **Redeploy**（环境变量只对新部署生效）。
4. 验证：浏览器打开 `https://你的域名/api/turn`，应返回包含 `iceServers` 的 JSON；进入对战后，延迟旁会显示 **直连** 或 **中转**。

未配置时接口返回 503，游戏自动退回仅直连，并在房间页提示"未获取到中转服务器"。本地开发时可这样启用：

```bash
CF_TURN_KEY_ID=xxx CF_TURN_API_TOKEN=yyy python3 tools/serve.py
```

### 其他说明

- 联机组件从 jsDelivr / unpkg 按需加载，需要联网。STUN 使用国内可达的 `stun.miwifi.com`、`stun.chat.bilibili.com` 及 Cloudflare、Google 的服务器。
- 若所在网络无法访问 PeerJS 公共信令服务，可自建：
  ```bash
  npm install -g peer && peerjs --port 9000 --path /peer
  ```
  然后在 `js/net.js` 的 `YY.NET_CONFIG.peer` 中加入 `host / port / path / secure` 配置。
- **微信 / QQ 内打开**：应用内置浏览器对 WebRTC 支持不完整，检测到时会提示好友点右上角「在浏览器打开」。
- **掉线与离开**：任一方切到后台（或锁屏）时会发送"暂时离开"心跳，比赛自动暂停并提示对方等待；超过 1.2 秒收不到对方输入/画面也会暂停并显示倒计时，15 秒仍无数据则判定断线，双方回到菜单。
- **加入失败的提示**：房间码不存在会立即提示；找到了房间但通道建立失败时，会区分"没有可用中转服务器"与"直连和中转都未连通"两种情况。
- 调试：两个标签页的 URL 都加 `?loopback=1`，即可通过 BroadcastChannel 在同一浏览器内联机，验证联机逻辑而不依赖 WebRTC。

## 代码结构

```
index.html        界面骨架（菜单、结算、帮助等）
css/style.css     界面与触屏按键样式
js/core.js        常量、羽毛球空气阻力物理、弹道求解
js/match.js       比赛逻辑：移动、跳跃、挥拍判定、球路、体力、计分
js/ai.js          击球点求解（AI 与练习提示共用）与三档 AI
js/practice.js    自由练习：发球机与提示
js/char.js        角色：骨骼姿态、着色、表情、头像
js/venues.js      场馆：屏幕几何、静态层与动态层（灯光、观众、天气、霓虹）
js/render.js      渲染器：镜头、分层合成、羽毛球与球迹、粒子特效、HUD
js/audio.js       WebAudio 合成音效
js/input.js       键盘与触屏输入
js/net.js         在线对战（PeerJS）、快照与好友端插值视图
js/main.js        模式管理、事件反馈、主循环
tools/sim.js           开发用：无界面 AI 对 AI 平衡测试，如 node tools/sim.js normal hard 10
tools/practice_sim.js  开发用：按提示操作的机器人验证各练习可完成
tools/serve_regression.test.js  发球、球网碰撞、击球显示与联机时序回归测试
tools/serve.py         开发用：禁用缓存的静态服务器（含本地 /api/turn）
tools/turn_api.test.js TURN 凭证接口测试：node --test tools/turn_api.test.js
api/turn.js            Vercel 函数：向 Cloudflare 申请 TURN 临时凭证
```

物理以 120Hz 固定步长运行。羽毛球使用二次空气阻力（终端速度约 11 m/s），因此高远球先快后慢、几乎垂直下落，扣杀出手极快但迅速减速。

运行发球与显示一致性回归：`node --test tools/serve_regression.test.js`。
