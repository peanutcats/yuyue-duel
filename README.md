# 羽跃对决 · 网页版

支持 2D 横版与 3D 纵深的 1v1 羽毛球游戏。使用 HTML5 Canvas 与原生 JavaScript，适配电脑键盘和手机横屏，无需构建即可运行。

## 2026-11-11 网页更新 · 1.24

- 阵容扩展至 20 名角色、80 个主动与被动技能，每场从三个主动中携带两个。自由人机和训练可使用全角色，并按角色保存技能及器械搭配。
- 新增 3D 纵深对战、固定摇杆与实时出球方向、空间 AI；支持人机、同屏双人与好友房间。自由对战可选 7 / 15 / 21 分制。

## 运行

```sh
python3 tools/serve.py
```

访问 [http://localhost:8765](http://localhost:8765)。也可直接打开 `index.html` 玩单机；好友邀请链接需要 HTTP(S) 地址。

静态文件可部署至 Vercel、GitHub Pages 或 Nginx。脚本与样式使用 `ink-124` 等版本标记避免混用旧缓存。

## 模式与操作

- 快速对战：2D / 3D、四档 AI、自选或随机对手、技能开关与自由器械。
- 好友对战：PeerJS / WebRTC 邀请码房间，或一台设备同屏双人；沿用 Cloudflare TURN 中转配置。
- 故事模式：《十六根羽毛》，本机独立存档；角色和装备解锁按剧情规则推进。
- 自由练习：接球、高远、吊球、跳杀与三拍战术教学，提供落点和挥拍提示。
- 挑战成就：各难度分别记录对每名角色的胜场，解锁并佩戴称号。

2D 单人：A / D 或左右键移动，W / 上键 / 空格起跳，J / K / L 击球，I / O 使用两个技能。

3D 单人：WASD 或方向键双轴移动，空格起跳，J / K / L 击球，I / O 使用技能。手机左侧固定摇杆同时控制走位与击球方向，右侧按键点按出手，松杆默认直线。

物理按 120Hz 固定步长计算；拍头、球网、边线与落点使用真实碰撞判定。7 / 15 / 21 分均需领先两分，分别在 11 / 21 / 30 分封顶。

## 在线配置

好友邀请码房间继续使用 `/api/turn` 申请临时 TURN 凭证。Vercel 环境变量为 `CF_TURN_KEY_ID` 与 `CF_TURN_API_TOKEN`，凭据不写入网页源码。未配置时退回直接连接。

公共在线匹配由 `js/online-config.js` 控制。纯静态发布默认关闭匹配；配置兼容物理规则 24、房间协议 2 的公开 `wss://` 比赛服务并允许本站 Origin 后，可将 `enabled` 改为 `true`，填写 `serverUrl`。同源反向代理 `/ws` 时可留空地址。原有好友邀请码房间独立运行。

本机进度、技能与器械方案保存于浏览器；不同浏览器和设备之间不自动同步。

## 维护与验证

使用 Node.js 22 或更新版本，无需安装 npm 依赖：

```sh
node --test --test-concurrency=2 tools/*.test.js
node tools/build-story-v3.js
node tools/export-story-art.js
node tools/export-character-art.js
```

- `index.html`、`css/`：网页菜单、手机控制与布局。
- `js/`：共享玩法、物理、角色、AI、声音、故事与网页联机客户端。
- `assets/story/sixteen/`：当前故事场景、CG 和原创音频；原作见 [STORY_SCRIPT_V3.md](STORY_SCRIPT_V3.md)。
- `assets/characters/index.html`：角色立绘册；`assets/skills/index.html`：技能图鉴。
- `tools/character-lab.html`：立绘、2D / 3D、双方站位与慢动作检视。
- [SKILL_DESIGN.md](SKILL_DESIGN.md)：角色与技能说明。

本次提交范围仅为网页版。微信小游戏与权威比赛服务在各自工程中维护，需要分别构建和部署。
